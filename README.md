# Mira

Mira is programmable link infrastructure for teams that need to create, control, distribute, measure and optimize every URL they put into the world.

Release `0.0.1` contains the product foundation and Roadmap Live. Customer capabilities remain pending until their milestone exit criteria pass.

## Development

```bash
npm install
npm run dev
npm test
```

The Roadmap Live is the source of truth for visible execution state. A completed task includes validation evidence; partial work does not count as progress.
